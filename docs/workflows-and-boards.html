Workflows and Boards

Interactive walkthrough of how North Star runs workflows (src/main/workflows/service.ts) and kanban boards (src/main/kanban/). You play the agent: pick what each turn returns and watch the state change.

Rules worth knowing

PromptStep instructions + earlier step results as untrusted reference data (bounded).
HandoffEach turn must end with handoff JSON: completed, unfinished, or a blocker.
Bad JSONOne tool-free repair turn. Still bad → step fails.
UnfinishedUp to 3 automatic continuation turns, each summarizing the transcript first.
ValidatorOptional, read-only, independent model. Rejection → correction turn; budget maxCorrectionLoops (default 2).
RetryRestarts from the first unfinished step with a fresh correction budget. Feedback leads the next message and overrides the plan.
ResumeKeeps the budget. Refused if a step has unknown side-effecting tool outcomes.
Browser / ElectronPer-step opt-in; max 4 such steps at once; tabs/apps don't survive pause.

Intake: tracker → Inbox (no LLM on replay)

Filter: tags agent-go (any), exclude agent-skip, assignee me

Same engine, different shape

Both are durable tasks on the shared task runner, run unattended Auto-mode turns, parse the same handoff, and bound prior results the same way (src/main/tasks/bounded-results.ts).
