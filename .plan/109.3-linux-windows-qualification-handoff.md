## Windows agent: native installed-CLI runs

Capture `Get-Command claude -All | Select-Object CommandType, Source`, `claude --version`, `node --version` and `pnpm --version`, then run the common checks. Inspect `$LASTEXITCODE` immediately after every external command: PowerShell may continue after a failure. These opt-in blocks preserve prior environment values and turn a failed test exit into an explicit failure:

```powershell
$previous = $env:NS_QUALIFY_INSTALLED_CLAUDE
try {
  $env:NS_QUALIFY_INSTALLED_CLAUDE = '1'
  node scripts/with-node-sqlite.mjs pnpm exec vitest run src/main/agent/providers/claude-subscription/installed-cli.test.ts
  if ($LASTEXITCODE -ne 0) { throw "Installed-CLI qualification failed: $LASTEXITCODE" }
} finally {
  if ($null -eq $previous) { Remove-Item Env:NS_QUALIFY_INSTALLED_CLAUDE -ErrorAction SilentlyContinue }
  else { $env:NS_QUALIFY_INSTALLED_CLAUDE = $previous }
}

$previous = $env:NS_QUALIFY_HOST_LOOP_INSTALLED
try {
  $env:NS_QUALIFY_HOST_LOOP_INSTALLED = '1'
  node scripts/with-node-sqlite.mjs pnpm exec vitest run src/main/agent/claude-subscription.integration.test.ts
  if ($LASTEXITCODE -ne 0) { throw "Installed host-loop qualification failed: $LASTEXITCODE" }
} finally {
  if ($null -eq $previous) { Remove-Item Env:NS_QUALIFY_HOST_LOOP_INSTALLED -ErrorAction SilentlyContinue }
  else { $env:NS_QUALIFY_HOST_LOOP_INSTALLED = $previous }
}
```
