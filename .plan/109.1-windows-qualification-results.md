## Implementation changes

Windows private transport root creation uses an explicit protected owner ACL, applied at creation rather than repairing public existing state. ACL checks reject foreign owners, allow entries for principals other than the current user/System/Administrators, missing owner full control, and reparse points. CWD, request directories and each request file are checked; children inherit the private root ACL. Existing untrusted state is rejected, not modified. ACL subprocesses use absolute system PowerShell, bounded capture and cancellation. Windows creation tests include spaces/non-ASCII names and explicit Everyone-readable disposable state.

File confinement now uses relative/absolute path checks on both platforms, including traversal and Windows alternate data stream rejection. Executable lookup recognizes Path casing and excludes relative PATH directories; npm shims remain unsupported. Windows managed-policy preflight checks documented Program Files files/drop-ins/MCP, the effective config remote cache, and both HKLM/HKCU registry views for policy-key presence without reading policy values. Probe errors fail closed. Documentation consulted: https://code.claude.com/docs/en/managed-settings.

Windows taskkill supervision now has a five-second fallback deadline. An owned native Node parent/descendant fixture proves abort terminates both. Request removal and installed fixture teardown have bounded Windows busy-handle retries. Installed fixtures retain SystemRoot/WINDIR and redirect HOME, USERPROFILE, APPDATA, LOCALAPPDATA and CLAUDE_CONFIG_DIR to disposable state.

Actual 2.1.295 initialization advertises an additional fable alias. This alias remains unsupported for requests and is deliberately omitted from the usable discovery catalog, like ambiguous default, instead of failing discovery for supported routes. Unknown other routes still fail closed. Windows discovery's total startup deadline is 60 seconds (the native protocol child still has a 15-second bound), allowing sequential ACL and policy checks. Installed fixture deadlines are 60 seconds; no generation/protocol acceptance boundary was broadened.
